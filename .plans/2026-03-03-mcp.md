# Model Context Protocol (MCP) Server

El objetivo es crear un servidor MCP ([Model Context Protocol](https://modelcontextprotocol.io/introduction)) para que agentes de IA conversacionales (como Claude, Cursor, o agentes desarrollados localmente) puedan entender la estructura y manipular datos dentro de HorneroDB de manera natural.

## Estructura del Servidor MCP

Desarrollaremos el servidor MCP preferentemente en **TypeScript** o **Python** (los SDKs oficiales más maduros), o en **Go** si deseamos compilar un binario estático junto a HorneroDB.
Asumiremos TypeScript por su robustez en el ecosistema MCP actual para conectores web. Vivirá en `/misc/connectors/mcp-server/`.

## 1. Configuración y Autenticación

El servidor MCP necesitará acceso a HorneroDB de forma desatendida.
Las variables de entorno requeridas serán:
- `HORNERODB_URL` (ej. `http://localhost:8080`)
- `HORNERODB_API_KEY` (API Key a nivel de Servidor o a nivel de Workspace, con permisos `admin` o al menos lectura/escritura).

## 2. Herramientas MCP (Tools)

El servidor MCP expondrá "Tools" (herramientas/funciones) a los LLMs, mapeando uno a uno con la API de HorneroDB.

### Tool: `list_workspaces`
- **Descripción**: Muestra los espacios de trabajo a los que el API Key tiene acceso.
- **Retorno**: Array de objetos con `id` y `name`.

### Tool: `list_tables`
- **Parámetros**: `workspace_id`
- **Descripción**: Muestra todas las tablas dentro de un espacio de trabajo.

### Tool: `get_table_schema`
- **Parámetros**: `workspace_id`, `table_slug`
- **Descripción**: **Crucial para la IA**. Llama a `/workspaces/:id/tables/:slug/columns` y devuelve la estructura exacta de la tabla (tipos de datos, cuáles son obligatorios, etc.). La IA *debe* usar esto antes de intentar insertar datos.

### Tool: `query_records`
- **Parámetros**: `workspace_id`, `table_slug`, `query` (OData query / querystring filters opcional).
- **Descripción**: Realiza búsquedas, filtrado y paginación en HorneroDB. Devuelve JSON.

### Tool: `create_record`
- **Parámetros**: `workspace_id`, `table_slug`, `data` (JSON Object).
- **Descripción**: Inserta datos nuevos en HorneroDB, validando dinámicamente el esquema subyacente.

### Tool: `update_record`
- **Parámetros**: `workspace_id`, `table_slug`, `record_id`, `data` (JSON Object).

### Tool: `delete_record`
- **Parámetros**: `workspace_id`, `table_slug`, `record_id`.

## 3. Prompts MCP (Atajos para el Usuario)

Adicionalmente, el servidor MCP puede ofrecer *Prompts* preconfigurados para acelerar la interacción del usuario en clientes que los soporten (como Claude Desktop).
- `analyze_table_data`: Toma el contenido completo de una tabla pidiendo a la IA que genere insights o resúmenes.
