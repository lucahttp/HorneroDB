## ✅ COMPLETADOS (4 Problemas Críticos)

### 1. Cookies sin flag Secure
**Archivos modificados**:
- `internal/config/config.go` - Agregados `Environment` y `SecureCookies` a ServerConfig
- `internal/middleware/cookies.go` - Nuevo helper `SetSecureCookie()`
- `internal/handlers/api/auth_oidc.go` - Usa `SetSecureCookie()`
- `internal/handlers/mcp/oauth.go` - Usa `SetSecureCookie()`

**Variables de entorno**:
- `HORNERO_ENV` (development/staging/production)
- `HORNERO_SECURE_COOKIES` (true/false, override manual)

### 2. SQL Injection en Export/Import
**Archivos modificados**:
- `internal/handlers/api/helpers.go` - Nuevas funciones:
  - `quoteIdentifier()` - Escapa comillas dobles
  - `ValidateAndQuoteTableName()` - Valida UUID + slug
  - `ValidateAndQuoteColumn()` - Valida columnas
- `internal/handlers/api/export.go` - Usa funciones seguras

### 3. SSRF en Webhooks (DNS Rebinding)
**Archivos modificados**:
- `internal/handlers/api/webhook.go` - `validateWebhookURL()` ahora:
  - Usa `net.LookupIP()` para resolución DNS en tiempo real
  - Verifica cada IP contra rangos privados
  - Previene DNS rebinding attacks

### 4. API Keys en Plaintext
**Archivos modificados**:
- `internal/handlers/api/apikey.go`:
  - Eliminado `key` de `ListAPIKeys` response
  - Solo muestra key completa en creación (una vez)
  - Agregado `key_mask` para referencia

## ⏳ PENDIENTES (14 Problemas)

### 🔴 ALTO (5 problemas)

#### 5. Sin Rate Limiting en Auth
**Archivos**: `internal/middleware/ratelimit.go`, `cmd/server/main.go`  
**Problema**: Endpoints OIDC (`/auth/oidc/login`, `/auth/oidc/callback`) sin rate limiting  
**Solución propuesta**: 
- Implementar rate limiting específico para auth
- Usar Redis para persistencia entre reinicios
- Limitar por IP y por failure

#### 6. Mass Assignment en UpdateRole
**Archivo**: `internal/handlers/api/role.go` (líneas 132-169)  
**Problema**: `UpdateRole` acepta `map[string]interface{}` sin whitelist  
**Código vulnerable**:
```go
var input map[string]interface{}
result := database.DB.Table("_hornero_roles").Where("id = ?", roleID).Updates(input)
```
**Solución**: Implementar struct con campos permitidos (como `UpdateWorkspace`)

#### 7. Debug logs con secrets
**Archivo**: `internal/services/auth/oidc.go` (líneas 296-297, 329)  
**Problema**: `fmt.Printf` expone `code_verifier` y datos sensibles  
**Solución**: 
- Reemplazar todos `fmt.Printf` con `slog.Debug()`
- Nunca loggear tokens o code verifiers
- Configurar nivel de log apropiado para producción

#### 8. Open Redirect
**Archivo**: `internal/handlers/api/auth_oidc.go` (línea 61-64)  
**Problema**: Parámetro `redirect` no validado contra whitelist  
**Código vulnerable**:
```go
redirectURI := c.Query("redirect")
if redirectURI == "" {
    redirectURI = baseURL + "/callback"
}
```
**Solución**: Validar `redirectURI` contra lista de URLs permitidas

#### 9. LocalStorage para JWT (Frontend)
**Archivo**: `web/ui/src/context/AuthContext.jsx` (líneas 16, 40, 47-49)  
**Problema**: Token JWT en `localStorage`, vulnerable a XSS  
**Solución**: 
- Considerar cookies `HttpOnly` para almacenar token
- Implementar refresh token rotation
- Agregar protección XSS estricta

### 🟡 MEDIO (6 problemas)

#### 10. Falta de CSRF Protection
**Archivos**: Todos los handlers POST/PUT/DELETE  
**Problema**: No existe protección CSRF explícita  
**Solución**: 
- Implementar tokens CSRF para operaciones sensibles
- Verificación estricta de headers Origin/Referer
- Configurar cookies con `SameSite=Strict`

#### 11. Headers de Seguridad Incompletos
**Archivo**: `internal/middleware/security.go`  
**Problema**: Faltan headers críticos:
- `Content-Security-Policy` (CSP) no configurado
- `Strict-Transport-Security` (HSTS) comentado
- `Permissions-Policy` no presente
**Solución**: Agregar headers faltantes con CSP nonce-based

#### 12. Validación de UUID Insuficiente
**Archivos**: `record.go`, `table.go`, `column.go`, etc.  
**Problema**: `recordID` no siempre validado como UUID antes de queries  
**Solución**: Middleware de validación de UUIDs para parámetros de URL

#### 13. Información Sensible en Logs
**Archivos**: `middleware/auth.go`, `handlers/api/*.go`  
**Problema**: Logs contienen `user_id`, `email`, `workspace_id`  
**Solución**: Revisar política de logging, implementar log sanitization

#### 14. Race Condition en Webhook Dispatch
**Archivo**: `internal/workers/webhook_dispatcher.go`  
**Problema**: Posible race condition si múltiples workers procesan mismo evento  
**Solución**: Verificar locking de PostgreSQL, considerar Redis para locking distribuido

---

### 🟢 BAJO (3 problemas)

#### 15. Código Muerto y Debug Statements

**Problema**: Comentarios de debug y código muerto
