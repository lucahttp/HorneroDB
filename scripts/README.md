# HorneroDB en Typebot

Dos maneras:

## 👉 Opción 1: Paso a paso manual (recomendado)

Seguí **[INSTALL.md](INSTALL.md)** — tiene 12 pasos claros, sin scripts automatizados.

## Opción 2: Script automático

**Bash/WSL:**
```bash
./setup-typebot.sh ~/workspace
```

**PowerShell:**
```powershell
.\setup-typebot.ps1 -ParentDir "C:\workspace"
```
